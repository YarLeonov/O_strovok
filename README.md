# О!дин запрос — AI Travel Agent

AI-агент для планирования путешествий, разработанный для хакатона **Ostrovok** (трек «О!дин запрос»). Помогает пользователям подобрать идеальную поездку через естественный диалог — от первого запроса до готовой корзины бронирования.

## 🚀 Быстрый старт

```bash
# Запуск через Docker
docker compose up --build

# Или через Makefile
make up
```

Откройте [http://localhost:8080](http://localhost:8080) — чат-интерфейс готов к работе.

## 📋 Что умеет агент

1. **Сбор требований** — бюджет, даты, количество гостей, дети, питомцы
2. **Вдохновение** — предложение направлений, если пользователь не знает куда поехать
3. **Поиск** — отели, рейсы, трансферы по критериям
4. **Сравнение** — варианты с оценками, причинами и рисками
5. **Формирование поездки** — проверка стыковок (время прилёта + заселение)
6. **Бронирование** — корзина с итоговой ценой и mock-оплата
7. **Новый поиск** — сброс и начало заново

## 📊 Данные

Все данные **синтетические** (mock data), что полностью соответствует требованиям трека:

- **15 отелей** — Анталья, Шарм-эль-Шейх, Дубай, Мальдивы, Сочи, Казань, Стамбул
- **9 рейсов** — SVO/DME → AYT/SSH/DXB
- **10 трансферов** — по ключевым направлениям
- **7 направлений** — с погодой и описаниями

```env
APP_PORT=8080
DB_URL=postgres://app:app@db:5432/app
OPENAI_MODEL=gpt-4o-mini
OPENAI_API_KEY=api_key
OPENAI_BASE_URL=http://openai:8000/v1
```

## 📝 Примечания

- **Synthetic Data** — все данные синтетические, реального ценообразования и бронирования не требуется
- **Platform** — `docker-compose.yml` указывает `linux/amd64` — важно для macOS/ARM
- **Non-root** — Dockerfile запускает от пользователя `app`
- **In-memory state** — сессии хранятся в памяти, данные теряются при перезапуске
